# Pink-Aesthetic-Site-Skin
**How To Add Skin:**

1. Copy the code

2. Go to Ao3, your username -> my dashboard -> skins -> create site skin (near the top right).

3. Give it a title, it has to be unique (I like to smash my keyboard at the end) then paste the code you copied in the CSS box.

4. Scroll to the end, hit submit.

5. Once it's created, just click "Use" to apply the skin.

**NOTE:** Some regions doesn't support pictures uploaded to tumblr. So I made another version of the code with a different image hosting site (which does work for those regions as far as I know). The other version is in the "alternate CSS Code" file.

**How to make it automatically switch between dark and light theme:**

Bear with me, it's a bit of a complicated process...

You would have to create three skins in total for this to work.

1. Copy the dark code

2. Go to Ao3, your username -> my dashboard -> skins -> create site skin (near the top right).

3. Give it a title, it has to be unique (I like to smash my keyboard at the end) then paste the code you copied in the CSS box.

4. In the "Advanced" box, select "Parent only" and In "Media" choose (prefers-color-scheme: dark)

5. Scroll to the end, hit submit.

6. Repeat steps 1-4 for the light theme (make sure you copy the light theme code and that you clicked (prefers-color-scheme: light))

7. Scroll to the end, hit submit.

8. Copy the Automatic Switch Code

9. Repeat steps 2 and 3

10. This time in the "Advanced" box, click "Add parent skin" and add both the dark and light theme skins you created. (NOTE: Don't click "parent only" for the automatic switch code!!! You won't be able to use the skin if you do)

11. Scroll to the end, hit submit.

12. Once it's created, just click "Use" (the Automatic switch one) to apply the skin.
